## 可用本地模型

| 模型 ID | 名稱 | 參數量 | Context | MaxTokens | Tool Use | 推薦用途 |
|---------|------|--------|---------|-----------|----------|----------|
| `ollama/qwen2.5:14b` | Qwen2.5 14B | 14.8B | 128K | 16384 | ✅ 支援 | **首選** — 文字處理、JSON、摘要 |
| `ollama/qwen3:8b` | Qwen3 8B | 8.2B | 32K | 8192 | ⚠️ 有限 | 簡單問答、翻譯 |
| `ollama/deepseek-r1:8b` | DeepSeek R1 8B | 8.2B | 32K | 8192 | ⚠️ 有限 | 需要推理的簡單任務 |
| `ollama/llama3.2:latest` | Llama 3.2 | 3.2B | 128K | 8192 | ❌ 不支援 | 極簡任務、草稿 |

---

## 子派語法

```
sessions_spawn(
  task="<任務描述>",
  label="<任務標籤>",
  model="ollama/qwen2.5:14b"
)
```

---

## 適合派給 Ollama 的任務

| 任務類型 | 推薦模型 | 說明 |
|----------|----------|------|
| 文字摘要 | qwen2.5:14b | 把長文縮短、提取重點 |
| 格式轉換 | qwen2.5:14b | Markdown ↔ JSON、表格整理 |
| JSON 處理 | qwen2.5:14b | 解析、轉換、驗證 JSON |
| Log 分析 | qwen2.5:14b | 讀取 log 找錯誤、統計 |
| 翻譯 | qwen2.5:14b / qwen3:8b | 中英互譯 |
| 模板生成 | qwen2.5:14b | 產生 RESULT.md、報告模板 |
| 簡單知識庫整理 | qwen2.5:14b | 不需要搜尋的重新整理 |
| 邏輯推理 | deepseek-r1:8b | 簡單推理、數學計算 |

---

## 不可以派給 Ollama 的任務

| 任務類型 | 原因 | 應該用什麼 |
|----------|------|-----------|
| 需要 web_search | Ollama 沒有搜尋工具 | kimi/kimi-k2.5 或 google/gemini-2.5-flash |
| 需要高品質推理 | 14B 模型能力有限 | kimi/kimi-k2.5 |
| 大量檔案讀寫 | context 比雲端模型小 | kimi/kimi-k2.5 |
| 需要圖片理解 | 本地模型只支援 text | google/gemini-2.5-flash |
| 複雜多步驟任務 | 容易出錯或卡住 | kimi/kimi-k2.5 |

---

## 模型選擇決策樹

```
任務進來
  │
  ├─ 需要搜尋？ → 不能用 Ollama → kimi 或 gemini
  │
  ├─ 需要圖片？ → 不能用 Ollama → gemini
  │
  ├─ 純文字處理？
  │   ├─ 簡單（摘要/翻譯/格式） → ollama/qwen2.5:14b ✅ 免費
  │   ├─ 中等（知識庫整理） → ollama/qwen2.5:14b ✅ 免費
  │   └─ 複雜（架構設計） → kimi/kimi-k2.5
  │
  └─ 需要推理？
      ├─ 簡單推理 → ollama/deepseek-r1:8b ✅ 免費
      └─ 複雜推理 → kimi/kimi-k2.5
```

## 成本比較

| 模型 | 每次呼叫成本 | 月估計（100次/天） |
|------|-------------|-------------------|
| ollama/qwen2.5:14b | $0 | $0 |
| kimi/kimi-k2.5 | ~$0.001 | ~$3 |
| google/gemini-2.5-flash | ~$0.002 | ~$6 |
| anthropic/claude-sonnet-4-5 | ~$0.05 | ~$150 |

**原則：能用 Ollama 就用 Ollama，省下來的額度留給真正需要的任務。**

---

## 注意事項

1. **Ollama 必須在本機運行** — 如果 `curl http://localhost:11434/api/tags` 沒回應，代表 Ollama 沒開
2. **首次載入較慢** — 模型第一次呼叫需要載入到記憶體，約 10-30 秒
3. **同時只能跑一個模型** — Ollama 預設同時只載入一個模型，切換模型會卸載前一個
4. **不要同時子派多個 Ollama 任務** — 會互相搶資源，一次一個就好
5. **失敗就升級** — 如果 Ollama 回應品質不行，立即改用 kimi/kimi-k2.5 重做
